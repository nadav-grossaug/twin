# TRANSFER: what moves between inside and outside

`artifacts/<variant>_seed<k>/` are the artifacts written by `snap/inside/fit_artifacts.py` and read by
`snap/outside/generate_synthetic.py`. They hold noisy summary tables and metadata, never nodes, edges or raw records.

Each artifact: `manifest.json` (SHA-256 of every file), `schema.json`, `privacy.json` (budgets, caveats),
`provenance.json` (allowlisted keys only), `measurements/` (JSON metadata + `.npz` values per table).
`artifacts/index.json` lists variant, nominal epsilon and seed (public settings).

Only seed 0 of each variant is committed; the other seeds are regenerated by stage 1. Format code: `src/graph_aim/transfer/`.
